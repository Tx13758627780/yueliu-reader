0.2.7：修复 TSX 路由导入遗漏，增加 316 个 RSSHub 配置入口；新增 Nature / 柳叶刀专用目录与柳叶刀系列期刊题录。B 站新增 UP 主动态（含图文），视频简介及专栏详情，安卓本地调用接口。延续 0.2.6 正式签名。

订阅目录扩展：79 个精选订阅，含 Nature 系列、《柳叶刀》官方目录及 Crossref 论文题录备用源；接入 Folo 公开目录的 1501 个平台、3066 个可配置 RSSHub 入口，支持搜索、分类、填写作者和栏目参数以及选择实例。目录为快照，未匹配路由的平台提供官方资料链接，不保证全部实时可用。

阅读笔记改为可拖动的浮动窗口，支持全屏、还原和收起，文字、手写、录音与选词问 AI 均保留。收起保留未保存草稿；点击笔记引用可回到原文。Android 返回手势优先还原全屏笔记，再收起浮窗。

新增 Android 应用内更新：在「离线与客户端」检查新版、查看更新说明、下载 APK、查看进度、取消或重试下载，再打开系统安装界面。下载后台继续；安装前核验来源、文件大小、可用的 SHA-256、应用包名、版本和签名。签名冲突时保留原应用及笔记，不自动卸载。

本版开始使用固定 Android release 签名，并修复正式版构建的网络配置检查错误。后续版本保持同一签名即可覆盖更新；缺少签名配置时构建会停止。旧临时测试签名与新签名不同，首次迁移须先导出并确认备份可用。

Android 系统侧滑 / 返回键现在逐层关闭下拉框、弹窗、侧栏，返回笔记列表和文章列表。回到首页后，第一次返回提示“再次滑动返回退出应用”，3 秒内再返回才关闭应用并移除最近任务。键盘、录音和未保存笔记优先处理，避免误退出。

Android 顶部操作区避开系统状态栏和摄像头区域，并额外下移 8 dp；底部避开手势条，横屏和软键盘弹出时重新计算可用区域。修复顶部按钮与时间、电量重叠、不便点击的问题。

这版补齐直接下载、离线页面更新和 Android 文件导出。

- Windows 安装版：下载名称含 `setup.exe` 的文件后安装。
- Windows 便携版：下载名称含 `portable.exe` 的文件后运行。
- Android：直接下载 `.apk` 到手机安装。
- `SHA256SUMS.txt` 提供以上文件的校验值。

支持离线阅读已保存文章、文字/手写/录音笔记、A4 与大画布以及片段引用。首次启动也可以离线创建笔记；新 RSS、全文下载、在线翻译和 AI 需要联网。

Android 导出备份和 OPML 时会打开系统“另存为”窗口。导入备份采用一次事务提交，写入失败时保留原数据。网页端会提示已下载的离线页面更新。

Windows 包尚未配置发布者签名；Android 使用固定 release 签名，不能直接覆盖旧临时测试签名版本。**更新前先导出备份，确认备份文件存在；遇到签名冲突后再卸载旧版、安装新版并导入。卸载会删除本机笔记。** 目前没有真机安装与手写笔兼容性测试，不作为应用商店发行包。

客户端笔记独立保存在设备上，可通过备份迁移，暂不自动与网页版同步。Windows 本机 RSSHub 需要 Docker Desktop；Android 需另用 Termux 启动。
